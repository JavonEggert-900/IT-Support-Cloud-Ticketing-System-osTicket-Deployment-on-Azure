# IT-Support-Cloud-Ticketing-System-osTicket-Deployment-on-Azure
Deployed osTicket v1.15.8 on a Windows 10 VM in Microsoft Azure. Configured IIS, PHP, MySQL and HeidiSQL from scratch. Set up roles, departments, SLA plans, agents and users as administrator. Simulated a full ticket lifecycle from end user submission to agent resolution. Performed security hardening and deleted all Azure resources.
